# Quiet Reader — Тихое чтение

Офлайн-читалка для Android: локальные книги, оглавление и сохранение позиции. Написана на Java с нативным интерфейсом Android; интерфейс приложения — русский.

Это личное приложение, созданное с помощью ИИ для повседневного чтения. Владелец определял требования, проверял предыдущие сборки на телефоне и давал обратную связь; основную реализацию выполнили ИИ-помощники. Исходники опубликованы для просмотра, сборки и дальнейшего улучшения. Проект дополняет основное инженерное портфолио.

**Статус: предварительная версия 0.2.1.** 18 ноября 2026 года владелец сообщил, что проверил приложение на телефоне и всё работает. Сборка и проверки парсера также успешно прошли в GitHub Actions.

## Возможности

- Добавление TXT, FB2, FB2 в ZIP, EPUB, HTML/HTM и PDF через системный выбор файлов.
- Локальная библиотека, сохранение позиции чтения и настроек оформления.
- Перелистывание текста свайпами, настройка шрифта, межстрочного интервала и полей; светлая, нейтральная тёмная и сепия-темы.
- Иерархическое оглавление по книгам и главам, если структура есть в исходном файле.
- Скрытие панелей чтения касанием центральной части экрана.
- Просмотр PDF с масштабированием и перемещением страницы.
- Работа без аккаунта и сервера: разрешение на доступ в Интернет не запрашивается.

FB2 разбирается потоковым SAX-парсером: сохраняются абзацы, стихотворные строки и границы строф, извлекаются метаданные и позиции заголовков. DTD и внешние сущности запрещены. Итоговый текст по-прежнему хранится в памяти; действуют ограничения размера и вложенности.

## Сборка

| Компонент | Версия |
| --- | --- |
| JDK для сборки | 21 |
| Уровень исходного Java-кода и байткода | 17 |
| Gradle Wrapper | 8.13 |
| Android Gradle Plugin | 8.13.2 |
| Compile SDK | 37 |
| Target SDK | 36 |
| Минимальная версия Android | 8.0 / API 26 |
| Build Tools | 36.0.0 |

Откройте папку проекта в Android Studio и выберите JDK 21 для Gradle. Установите компоненты Android SDK:

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
```

Укажите путь к SDK в переменной `ANDROID_HOME` или в локальном файле `local.properties`: `sdk.dir=/path/to/Android/Sdk`. Затем выполните из корня репозитория:

```sh
# Linux / macOS
bash ./gradlew --no-daemon assembleDebug
```

```powershell
# Windows PowerShell
.\gradlew.bat --no-daemon assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Gradle создаёт локальный отладочный ключ; приватные ключи в репозиторий не включены. Отладочная сборка предназначена для локальной проверки.

## Проверки и их границы

Тесты парсера запускаются на обычной JVM без устройства и Android SDK:

```sh
bash tests/run-parser-checks.sh
```

```powershell
.\tests\Run-ParserChecks.ps1 -DevJdkRoot $env:JAVA_HOME
```

На синтетических данных прошли **315 + 40 проверок условий в тестах парсера**: 315 проверок разбора текста и позиции чтения, 40 — потокового разбора FB2. Это не 355 отдельных тестов приложения и не проверка всего интерфейса.

В [GitHub Actions](.github/workflows/android.yml) настроены запуск этих проверок и сборка debug APK; [запуск от 18 ноября 2026 года прошёл успешно](https://github.com/GrantCanyon/quiet-reader-android/actions/runs/44259341727). В workflow нет эмулятора, Android instrumentation, автоматизации интерфейса или полной книги, защищённой авторским правом. Подробности и необязательные проверки на устройстве: [tests/README.md](tests/README.md).

Ручная проверка на телефоне подтверждена владельцем 18 ноября 2026 года: по его сообщению, оба приложения работают. Подробный протокол с номером APK, моделью устройства и перечнем сценариев не предоставлялся; результат записан как пользовательская проверка работоспособности.

## Ограничения

- EPUB, FB2 и HTML преобразуются в читаемый текст: изображения, сложная типографика и исходная вёрстка полностью не воспроизводятся.
- Нет DRM, MOBI/AZW, DJVU, облачной библиотеки, синхронизации и OCR.
- Слишком большие или повреждённые файлы могут быть отклонены ограничениями импорта.
- В репозиторий не входят книги и личные данные чтения. Для проверки используйте файлы, на использование которых у вас есть право.

Основные части проекта — activity, локальный репозиторий книг, парсеры форматов, миграция позиции чтения и PDF-представление. Их обязанности и оставшиеся проверки описаны в [заметках о разработке](docs/DEVELOPMENT.md).
